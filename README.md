# PITAAAN！備品・発注リスト（GitHub Pages版）セットアップ手順

所要時間の目安：30〜40分。パソコンで作業してください。

## このフォルダに入っているもの

- `index.html` … リスト本体
- `config.js` … 設定ファイル（手順2で書き換えます）
- `firestore.rules` … 会社のアカウントだけに使わせるための設定（手順2で使います）
- `README.md` … この手順書

---

## 1. GitHubに置いて公開する

1. https://github.com でアカウントを作ってログインします（会社のメールアドレスで大丈夫です）。
2. 右上の「＋」→「New repository」を選びます。
3. Repository name に `pitaaan-order-list` と入力し、**Public** を選んで「Create repository」を押します。
   - 無料プランのGitHub Pagesは Public のみ使えます。ファイルの中身（画面の作り）は誰でも見られますが、**在庫データはFirebaseに保存され、会社のアカウント以外は見られません**。
4. 作成後の画面で「uploading an existing file」を押し、このフォルダの5つのファイルをまとめてドラッグして「Commit changes」を押します。
5. 「Settings」→ 左メニューの「Pages」を開きます。
6. 「Branch」で `main` と `/ (root)` を選び、「Save」を押します。
7. 1〜2分待つと、上に `https://（ユーザー名）.github.io/pitaaan-order-list/` というURLが表示されます。これがリストのURLです。メモしておいてください。

## 2. Firebaseの準備（在庫データの保存先とGoogleログイン）

### 2-1. プロジェクトを作る
1. https://console.firebase.google.com を開き、会社のGoogleアカウントでログインします。
2. 「プロジェクトを作成」→ 名前に `pitaaan-order-list` と入力して進めます。Googleアナリティクスはオフで大丈夫です。

### 2-2. Googleログインを有効にする
1. 左メニュー「構築」→「Authentication」→「始める」を押します。
2. 「Sign-in method」タブで「Google」を選び、「有効にする」をオンにして、サポートメールを選んで「保存」します。
3. 同じ画面の「設定」タブ →「承認済みドメイン」→「ドメインを追加」で、`（ユーザー名）.github.io` を追加します（手順1-7のURLの `https://` と `/pitaaan-order-list/` を除いた部分）。

### 2-3. データベースを作る
1. 左メニュー「構築」→「Firestore Database」→「データベースの作成」を押します。
2. ロケーションは `asia-northeast1（東京）` を選びます。
3. 「本番環境モードで開始する」を選んで「作成」します。
4. 「ルール」タブを開き、中身をすべて消して、`firestore.rules` の中身を貼り付けます。
5. 貼り付けた中の `YOUR-DOMAIN` を、会社のメールアドレスの「@」より後ろ（例：`itnav.co.jp`）に書き換えて「公開」を押します。

### 2-4. 設定値を config.js に入れる
1. 左上の歯車 →「プロジェクトの設定」→「全般」タブの下の方「マイアプリ」で、`</>`（ウェブ）のマークを押します。
2. アプリのニックネームに `pitaaan-order-list` と入れて「アプリを登録」します（Firebase Hostingのチェックは不要です）。
3. 表示された `firebaseConfig = { ... }` の中の値（apiKey、authDomain など）を、`config.js` の同じ名前の `""` の中に貼り付けます。
4. `allowedDomain` にも、会社のメールアドレスの「@」より後ろを入れます。
   - apiKey などは公開されても問題ない値です。データを守っているのは手順2-3のルールです。

### 2-5. config.js をGitHubに上げ直す
1. GitHubのリポジトリで `config.js` を開き、鉛筆マーク（Edit）を押します。
2. 中身を書き換えた `config.js` の内容に置き換えて「Commit changes」を押します。
3. 1〜2分後、リストのURLに反映されます。

## 3. 使い始める

1. リストのURLを開き、「Googleでログイン」から会社のアカウントでログインします。
2. claude.ai版の備品データは取り込み済みです（取り込みに使った `initial-data.js` は、公開リポジトリに残さないよう削除しました）。
3. 「在庫」タブ →「QRコードを印刷する」から、QRコードを印刷して棚に貼ります。
4. リストのURLを、Slackの #備品購入関連 にピン留めしてスタッフに共有します。

## うまくいかないとき

- **「設定ファイルにFirebaseの情報がまだ入っていません」と出る** → 手順2-4・2-5を確認してください。
- **ログイン画面がすぐ閉じる・エラーになる** → 手順2-2の「承認済みドメイン」に `（ユーザー名）.github.io` が入っているか確認してください。
- **ログインできたのに「備品リストを見られません」と出る** → 手順2-3のルールの `YOUR-DOMAIN` の書き換えを確認してください。
- **会社以外のGoogleアカウントでログインしてしまった** → 「使い方」タブの一番下にある「ログアウト」から、ログインし直してください。
